# Scope Creep™

**The productivity tool that guarantees you never ship.**

A Funny & Creative hackathon project: a premium-looking product studio that starts with one tiny idea and recommends “absolutely essential” features until the ship date is NEVER.

## Stack

React + Vite + TypeScript. Fully static. No backend.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is in `dist/`. GitHub Pages is configured with base `/scope-creep/`.

## GitHub Pages

Push to `main`. The workflow builds and deploys `dist` to Pages. Enable Pages (GitHub Actions source) in the repository settings if it is not already on.
